Full Stack Development (FSD)

This repository contains my Full Stack Development practical work and chapter-wise exercises.

Important Setup Instructions

Chapter 7 – Node Modules

In Chapter 7, the "node_modules" folder has been removed before uploading to GitHub because of its large size.

After downloading or cloning the project, open the Chapter 7 project folder in the terminal and run:

npm install

This will automatically install all required dependencies using the "package.json" file.

T4 – Frontend, Backend & MongoDB

The T4 practical contains frontend and backend connection work with MongoDB.

Only the "Front-Back_HAND" project folder is included in this repository. The separate MongoDB installation folder is not uploaded because it contains MongoDB/MongoDB Shell installation files rather than project source code.

To run the MongoDB-related practicals locally, make sure MongoDB for Windows and the required MongoDB tools are installed on your system.

Chapters 9 & 10 – MongoDB / Mongoose

Chapters 9 and 10 contain MongoDB-related practicals.

The database operations and queries are performed using MongoDB with Mongoose in the Node.js environment. Therefore, MongoDB should be properly installed and running before executing these practicals.

Note

- "node_modules" is removed only where necessary to reduce the repository size.
- Run "npm install" in a project folder if its "node_modules" directory is not included.
- MongoDB installation files are not included in this repository.
- "package.json" and "package-lock.json" are kept so the required Node.js dependencies can be installed easily.
